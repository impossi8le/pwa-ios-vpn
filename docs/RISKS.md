# RISKS.md — Ограничения и риски

## Ограничения, которые важно знать заранее

### 1. «Команды» работает не в фоне
`shortcuts://run-shortcut` открывает приложение «Команды» на **передний план**, показывает баннер выполнения. Safari **каждый раз** спрашивает «Открыть в "Команды"?». Тихого фонового запуска Shortcuts с веб-страницы на iOS **не существует** (мак-версия «Shortcuts Events» — только macOS).

**Митигация**: честный UX («Нажмите "Открыть"»), возврат в PWA через x-callback.

### 2. Установка профиля — не «в один клик»
1. Safari: «This website is trying to download a configuration profile. Allow?» → Allow
2. Настройки → Профиль загружен → Install
3. В течение **8 минут** (иначе профиль авто-удаляется)

### 3. Stolen Device Protection (iOS 17.3+)
При включённой «Защите украденного устройства» установка профиля **блокируется**.
**Митигация**: инструкция «Настройки → Face ID & код → Защита украденного устройства → выключить → установить профиль → включить обратно».

### 4. App Store правило 5.4 (VPN Apps)
> «Apps offering VPN services must utilize the NEVPNManager API… Apps offering **configuration profiles** must also adhere to these requirements.»

PWA — **не приложение**, поэтому 5.4 к веб-странице напрямую не применяется. Туннель строит одобренный OpenVPN Connect. Риск — «против духа» правил (низкий).

### 5. Территориальные блокировки (РФ, КНР)
Apple удаляла VPN-приложения: в РФ — NordVPN/Proton/PIA (июль 2024, по требованию РКН), в Китае — все (2017, лицензия MIIT). Если аудитория в РФ — OpenVPN Connect может быть недоступен в местном App Store.

**Митигация**: проверить регион заранее; запасной план — собственный NEVPNManager-апп от организации.

### 6. Пограничный случай: Set VPN vs OpenVPN Connect
Механизм действия Set VPN подтверждён (L2TP, WireGuard), но **прямого теста на профилях OpenVPN Connect не найдено**. Есть двойная страховка — встроенные Siri-Shortcuts OpenVPN Connect v3.3+.

**Митигация**: протестировать на реальном устройстве до запуска; при проблемах использовать встроенные Siri-Shortcuts приложения.

### 7. Safari блокирует запуск схемы без жеста
Программный `window.location.href` к `shortcuts://` сработает только **из обработчика тапа** (пользовательского жеста). Автоматический запуск при загрузке страницы — нет.

### 8. Профиль unsigned
Неподписанный `.mobileconfig` устанавливается с предупреждением «Unsigned». Идеально — подписать (Apple Push Certificates / CA).
